# Construction Intelligence Hub

A premium, modern, and production-quality Streamlit frontend for an AI-powered construction operations and intelligence center. Designed with an enterprise-level aesthetic resembling Oracle Primavera, Procore, and Autodesk Construction Cloud.

## Features

- **Executive Dashboard**: High-level KPIs, project summaries, visual expense tracking, and recent activity logs.
- **Project Management**: Multi-project tracking with status highlights, progress indicators, search, and granular filters.
- **Workforce Management**: Allocation visualizers, role statistics, and comprehensive attendance rosters.
- **Material Management**: Stock level tables, automatic threshold warnings, suppliers tracker, and usage trends.
- **Budget & Finance**: Expense breakdown donut charts, monthly spend S-curves, and approval status trackers.
- **Safety & Risk (HSE)**: Risk heatmaps, safety checklist audits, OSHA compliance indicators, and emergency contacts.
- **AI Insights & Predictions**: Dynamic cards showing predictive health scores, delay probabilities, cost overruns, and resource reallocations.
- **ConstructAI Assistant**: A responsive chatbot interface with suggested operational questions and custom mock responses.
- **Reports**: Analytical summaries with options to export/download generated analytical reports.

## Tech Stack

- **Frontend**: Streamlit, Custom HTML/CSS
- **Visualizations**: Plotly Express
- **Data Engine**: Pandas, NumPy

## Getting Started

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Application**:
   ```bash
   streamlit run app.py
   ```

3. Open your browser and navigate to `http://localhost:8501`.
